Privacy Policy – Panen SiRUP

Effective date: October 6, 2026 · Bahasa Indonesia di bawah

Panen SiRUP ("the app") is a free desktop application that runs on the user's own Windows computer. It collects publicly available government procurement plan data from SiRUP (sirup.inaproc.id), saves it as CSV files on the user's computer, and, if the user chooses, writes it to a Google Sheet in the user's own Google Drive. This policy explains what data the app accesses, how it is used, and how users stay in control.

1. Information the app accesses

The app only accesses Google user data after the user clicks "Hubungkan Google" (Connect Google) and grants permission on Google's consent screen.

Google permission (scope)What it allowsWhy the app needs it
openid, userinfo.emailRead the email address of the signed-in Google account. Only to show the user which account is connected ("Connected as …").
drive.fileCreate files and access only the files this app created. To create one spreadsheet named "Data Pengadaan SiRUP" and add/update procurement data in it.

The app cannot see, read, modify, or delete any other file in the user's Google Drive. It does not access Gmail, contacts, calendar, or any other Google service. It does not collect names, phone numbers, location, or device identifiers.

2. How the information is used

  • The email address is displayed inside the app so the user knows which account is connected.
  • The drive.file access is used solely to create and update the user's "Data Pengadaan SiRUP" spreadsheet with the procurement data the user chose to collect, and to add a log row for each upload.
  • Google user data is not used for advertising, profiling, analytics, or training AI/ML models, and is not used for any purpose other than the features described above.

3. Storage and retention

  • The app has no server. The developer never receives or stores any user data.
  • After sign-in, Google's access token and refresh token, together with the account email, are stored only on the user's own computer in a local file (token_google.json) in the app folder.
  • This local file is kept until the user clicks "Putuskan akun Google" (Disconnect), deletes the file, or revokes access in their Google Account.
  • Procurement data is stored in CSV files on the user's computer and in the user's own Google Sheet, which the user fully owns and controls.

4. Sharing

Google user data is not sold, rented, transferred, or shared with any third party. Network requests go only to Google APIs (to sign in and to write to the user's own spreadsheet) and to the public SiRUP website (to fetch public procurement data, which contains no Google user data).

5. Security

All communication with Google and SiRUP uses HTTPS. Tokens stay on the user's computer. Users should not share the token_google.json file, because it grants access to the spreadsheet created by the app.

6. User control and deletion

  • Disconnect inside the app with "Putuskan akun Google"; this deletes the local token file.
  • Revoke the app's access at any time at myaccount.google.com/permissions.
  • Delete the "Data Pengadaan SiRUP" spreadsheet from Google Drive at any time.

7. Limited Use disclosure

Panen SiRUP's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Children

The app is a work tool for procurement research and is not directed at children under 13.

9. Changes to this policy

Changes will be published on this page with a new effective date.
