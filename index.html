Panen SiRUP

Aplikasi desktop untuk mengumpulkan data rencana pengadaan publik dari SiRUP ke Google Sheets.
A desktop app that collects public procurement plan data from SiRUP into Google Sheets.

Apa yang dilakukan aplikasi ini

Panen SiRUP berjalan di komputer pengguna sendiri. Aplikasi ini mengambil data paket pengadaan yang terbuka untuk umum dari situs SiRUP (sirup.inaproc.id), merapikannya, lalu menyimpannya sebagai file CSV.

Jika pengguna memilih Hubungkan Google, aplikasi membuat satu Google Sheet bernama "Data Pengadaan SiRUP" di Google Drive pengguna dan menulis data ke sheet tersebut. Aplikasi hanya bisa membuka file yang dibuatnya sendiri (izin drive.file), tidak bisa membaca file lain di Drive pengguna.

What this app does

Panen SiRUP runs locally on the user's computer. It collects publicly available procurement package data from SiRUP (sirup.inaproc.id), cleans it, and saves it as CSV files.

If the user chooses Connect Google, the app creates one Google Sheet named "Data Pengadaan SiRUP" in the user's Google Drive and writes the data there. It only accesses files it created itself (drive.file scope) and cannot read any other file in the user's Drive.
